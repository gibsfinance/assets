## Browsing

- Select a chain from the grid of popular chains, or from the dropdown.
- Browse the paginated token list. You can search inside it.
- Filter by provider lists. You can switch single providers on and off.

The studio shows the top chains by token count. Use the dropdown to reach all 200 or more supported chains. Switch on "Show Testnets" to see test networks.

## Token deduplication

When several lists carry the same token:

- The studio shows one row, with the best image. Vector images are preferred.
- A chevron expands the row to show every list that references the token.
- Each sub-row shows its image, a format badge and links.

## Global search

- Type a query and press Enter to search across all chains.
- The search covers all lists and all chains.
- Results are sorted by chain, with Ethereum first, and then by name.

The server behind this search is described in [Search](/api-reference/search/).
